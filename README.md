# 🔐 User Authentication & Storage with JDBC, Hibernate or JSON

## 🎯 Project Goal  
Celem projektu było stworzenie konsolowej aplikacji backendowej w Javie, która umożliwia zarządzanie wypożyczalnią pojazdów. Projekt demonstruje obsługę danych związanych z użytkownikami, pojazdami oraz procesem wypożyczenia z wykorzystaniem JDBC, Hibernate i formatu JSON. Całość działa poprzez terminal i zapisuje dane w bazie PostgreSQL.

## 📄 Description  
Aplikacja zawiera następujące funkcjonalności:

- Rejestracja i logowanie użytkowników.
- Dodawanie i usuwanie pojazdów do systemu
- Wypożyczanie i zwracanie pojazdów przez użytkowników.
- Dwa warianty komunikacji z bazą danych:
  - **JDBC** – bezpośrednie zapytania SQL.
  - **Hibernate** – dla operacji ORM na encjach.
- Wykorzystanie formatu **JSON** do:
  - Parsowania danych z pliku.
